# Cthulhu Daemon — 90-second demo

Use only the public repository, public report, and fictional-data evidence. This outline does not imply that a video has already been recorded.

## 0–15 seconds: the problem

Show the [repository](https://github.com/robs46859-eng/arkham-creeper).

“Cthulhu Daemon prepares code-review context in the background. It catches signed repository changes, keeps their source inert, and leaves the final decision to a human.”

## 15–40 seconds: measured execution

Open [the demonstration](https://cthulhu.arkhamprison.com/). Show the saved-run label, four scenario cards, and boundary checks.

“These are fictional inputs with real execution: HTTP signature checks, a durable queue, and local Gemma inference. All 18 orchestration/rehearsal assertions passed. The executable-text fixture did not run.”

Show the virtual rehearsal and expand a probe record.

“A separate trusted fictional service passes 13 security-contract probes. The same probes expose deliberately planted tenant and consent defects. This tests the harness; it does not certify a real application or execute incoming source.”

## 40–60 seconds: inspect the AI

Read a model-review card and show the JSON link.

“Gemma reads bounded excerpts and drafts advisory context. Four reviews measured 1,073 prompt tokens and 437 output tokens, with model unload observed afterward. Its false positive about the benign dictionary `get()` stays visible. Model output cannot run code or apply a patch.”

## 60–80 seconds: show automation

Open the [validated runtime’s passing GitHub Actions run](https://github.com/robs46859-eng/arkham-creeper/actions/runs/40246949823).

“The runtime passes 69 tests and the 18-assertion simulation. The six animal-inspired roles cover capture, memory, triage, rest, provenance, and resilience within one pipeline.”

## 80–90 seconds: the hook

Return to the public report.

“The payoff is less manual intake and repeatable review preparation—not an invented hours-saved figure. Code flows in. Evidence surfaces. You keep the final call.”

If recording, exclude account dashboards, private applications, terminals containing secrets, and development transcripts. Test any published video link logged out before adding it to the submission.
