# Six animal-inspired roles, one review pipeline

Cthulhu Daemon is a biomimetic Symbiont, not just a Man o’ War listener. These names describe engineering roles in one pipeline, not six autonomous agents or scientifically validated biological simulations.

| Inspiration | Current engineering role | Boundary |
| --- | --- | --- |
| **Portuguese man o’ war — capture** | The Sail receives signature-verified repository webhooks. Tentacles enforce the allowlist and replay checks; Deep Water holds inert payload/source data. | No payload execution; the queue is not an OS sandbox. |
| **Clark’s nutcracker — pattern memory** | A reproducible synthetic baseline gives IsolationForest a reference for structural novelty. Reports retain source hashes and feature scores. | Not CART, ChromaDB, photographic memory, persistent online learning, or verified threat detection. |
| **Prairie dog — signal triage** | Configured rules and Gemma's bounded contextual advice organize signals for human review. AI cannot downgrade configured findings. | False positives remain possible and visible; no claim that alerts are eliminated or threats verified. |
| **Dolphin — model rest** | Gemma requests `keep_alive: 0`; the worker observes whether the model remains loaded after a review. | Unloading is measured, not guaranteed by the request alone. No echolocation swarm, active quarantine, or thermal optimization is claimed. |
| **Wolf — traceability** | Commit SHA, path, Git blob identity, and source hashes tie findings to the exact captured change. | This is provenance, not implemented semantic tracking across refactors or a persistent vulnerability graph. |
| **Beaver — durable containment of work** | Transactions, backlog limits, leases, bounded retries, rollback-aware code updates, and dead letters keep work recoverable. | Recovery concerns the workflow. Autonomous repair patches, quarantine branches, and self-healing production code are not implemented. |

The original concept's advanced wolf tracking and beaver patching remain future work. This build carries the broader animal-inspired design without representing those proposed capabilities as delivered features. Private products and their source stay outside this public installation.

**Code flows in. Evidence surfaces. You keep the final call.**
